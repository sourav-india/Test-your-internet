Questions, answered

Frequently asked

Does this use a real speed test?+

Yes. The test measures the time required to transfer actual bytes between your browser and this server. Results reflect the route and conditions available at test time.

Why can results change between tests?+

Wi-Fi signal, other devices, VPNs, server load, and routing can all affect performance. Run a few tests at different times for a broader view.

Is my result stored online?+

No. Recent results are saved only in your browser’s local storage. You can clear them at any time.
